# Quill 1.0.0 Beta 1

First downloadable beta of Quill, a native macOS menu bar app that corrects selected writing in place.

## Download and install

Download **Quill-1.0.0-beta.1-universal.dmg** from Assets below. Open it, drag Quill to Applications, then launch it from Applications. Read the included **Start Here.html** or the [setup guide](https://github.com/Nozibulla/Quill/blob/v1.0.0-beta.1/docs/BETA-SETUP.md).

**Requirements:** macOS 14+, internet access, a compatible separately installed Codex runtime, and ChatGPT sign-in with Codex access. The runtime is not bundled. Tested with Codex `0.158.0-alpha.2.1`; compatibility with other versions is not guaranteed.

**This beta is not notarized or Developer ID signed.** After trying to open it, users who trust the download can use System Settings → Privacy & Security → Open Anyway for the unidentified-developer warning. [Apple's instructions](https://support.apple.com/en-us/102445). Managed Macs may block installation. Accessibility approval is also required.

## Included

- Select text and press ⌘⇧E to correct it in the original field.
- Verified paste before reporting success; cancellation and changed-field safeguards.
- Eight writing styles, model selection, and optional Fast speed.
- Manual editor and Copy fallback.
- MIT-licensed source code.

The universal app contains Apple Silicon and Intel code. Apple Silicon has been tested; Intel and macOS 14 have not been exercised end to end. ChatGPT draft replacement is verified; Teams and other editors remain unverified. Corrections use your shared Codex allowance and send the selected writing to OpenAI.

The existing 27-test suite passed before packaging. Release packaging checks cover both architectures, signature integrity, disk image integrity, and included files. This is an early beta, not a guarantee of compatibility with every Mac or editor.

SHA256SUMS.txt contains the disk image checksum. Setup instructions are also available as a separate text download. Please report problems using synthetic text in GitHub Issues.
