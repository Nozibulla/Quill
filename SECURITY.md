# Security

Quill handles selected writing, temporary clipboard contents, and access to other apps through macOS Accessibility. Reports about unintended text disclosure, wrong-field replacement, credential exposure, or session isolation are welcome.

Please do not put sensitive vulnerability details, credentials, or private writing in public issues. Use GitHub's **Report a vulnerability** option in the repository's Security tab if private vulnerability reporting is enabled. If it is unavailable, open an issue asking the maintainer for a private reporting channel without including exploit details.

Include the affected revision, macOS and runtime versions, reproduction steps using synthetic text, and the expected impact. Remove personal information from logs and screenshots.

Security fixes target the current development branch. There is no separate long-term support release policy.
